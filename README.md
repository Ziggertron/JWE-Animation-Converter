# JWE-Animation-Converter
JWE Animation Converter is a Windows tool for extracting Jurassic World Evolution animations from OVL archives and exporting them as GLB files. Choose a skeleton for animation-only exports or a model to include the skinned mesh and rig. Each animation clip is saved separately with its original frame rate.

Includes the Windows executable and full source code. Requires Blender 5.0. Tested with Jurassic World Evolution 1; JWE 2 and 3 support is experimental. Textures are not exported.
